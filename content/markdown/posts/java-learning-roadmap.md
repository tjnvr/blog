# Ma feuille de route pour maîtriser Java

J'ai l'occasion de développer en Java chez Piano. Mon équipe originelle s'étant recomposée, je suis amené à travailler sur un périmètre beaucoup plus large dont ce langage fait partie. De la même manière que j'ai pris le temps de creuser la documentation et les paradigmes du Go précédemment, le temps est venu de décortiquer Java.

Ceci est mon fil d'Ariane pour m'y retrouver dans mon apprentissage du langage. Mon objectif est d'abord de me sentir plus à l'aise en Java (maîtriser la syntaxe du langage, approfondir les concepts de la programmation orientée objet, manipuler les bibliothèques connues) tout en documentant les ressources étudiées.

L'idée est de me construire une feuille de route vivante où je documente mon avancement.
